# MissAV Via 辅助

给 [Via](https://via-app.cn/) 用的 MissAV 用户脚本，当前版本 **1.11.0**。

安卓和 iOS 使用同一个安装包。脚本先走安卓可用的「插入页面脚本」；如果这段脚本没有执行（iOS 的 Via 会这样），再在当前页面里直接接手势。标记写在页面上，后一条发现前一条已经运行就会退出，因此两条路径不会同时生效。

亮度和音量只调当前视频，不依赖外部服务；iOS 上视频音量不能由网页修改，这项差异不单独再发一个插件。

匹配 `missav.ai`、`missav.com`、`missav.ws`、`missav.live`、`thisav.com` 及其子域名。

安装或更新地址：

https://github.com/Elijah-Neverdie/via-scripts/releases/latest/download/missav.user.js

在 Via 里打开「设置 → 脚本 → 更新」。更新后刷新正在看的视频页，新手势才会生效。

## 已完成的功能

### 播放

- 单击画面只开关原生控制条（进度、播放、音量、设置、全屏），不会因此播放或暂停。
- 双击左侧三分之一后退 15 秒，画面左侧中央显示 `-15s`。
- 双击中间三分之一播放或暂停。
- 双击右侧三分之一前进 15 秒，画面右侧中央显示 `+15s`。
- 连续快进、快退会累加，并合并成一次跳转，避免音画不同步。竖屏、横屏和全屏都按画面三分区判断。
- 提示只有带阴影的文字，没有底框，也不加粗；字号参考视频标题。全屏时按画面面积缩放。
- 控制条展开后，额外提供 10 秒、1 分钟、10 分钟的快进和快退，全屏同样可用。
- 进入播放页保持暂停，使用页面原有的中央播放按钮。
- 左上角显示网速和视频的真实分辨率（直接读取视频高度，例如 `928P`），点击可以选择清晰度。

### 手势

- 在画面左半边上下滑动，调节视频亮度，最高为当前系统亮度。
- 在画面右半边上下滑动，调节视频音量，最高为当前系统音量。
- 在画面上左右拖动，调整播放进度，画面中央显示目标时间；横跨整个画面约等于 300 秒（不足 300 秒的视频按总时长）。
- 长按画面 0.5 秒后不松手，左右拖动同样可以调整进度。
- 拖动时只在固定间隔跳转，松手时再精确跳到最终位置。

### 界面

- 首页仍是原来的视频网格，不出现播放和快进层。
- 去掉播放器下方带「循环播放」的那一行，以及同一条黑底里的内容，中间不留空白。
- 播放器齿轮改为下载图标。点击后复制当前正在播放的地址，并提示「已复制下载链接」，不会打开设置菜单。
- 分享按钮旁边的按钮改为「BTSOW」，点击后打开 `https://btsow.live/search/番号`，例如 DAL-013。
- 「收藏」「片单」右侧的「下载」改为弹出磁力下载列表，数据来自页面里的「磁力下载」标签；每一项右侧有「Download To Nas」按钮，点击后直接提交到 NAS 迅雷。

### 广告

- 屏蔽延迟出现在右下角的悬浮广告。
- 推荐视频卡片保持显示，不会被误藏，也不会在右下角来回闪烁。

## 下载到 NAS 迅雷

按钮外观和规则沿用 [bts_web_tool](https://github.com/Elijah-Neverdie/bts_web_tool)，但不打开迅雷网页，而是直接调用 NAS 迅雷（`cnk3x/xunlei`，端口 2345）网页所用的接口提交任务，所以在 Via 里也能用。

- 首次使用：点击磁力列表右上角「NAS 设置」，或长按任意「Download To Nas」按钮，填写迅雷网页的账号和密码。IP 留空会自动在 `10.10.10.10` 和 `10.144.0.1` 中选延迟最低的。
- 下载目录固定为「迅雷测试」，NAS 迅雷里没有这个目录就停止。
- 只下载视频：只看迅雷默认勾选的文件；视频体积不足默认勾选总大小的 45% 就跳过；视频都小于 50MB 时下载默认勾选的全部文件；否则排除非视频和不足最大视频 10% 的广告小片。
- 提交前按磁力哈希查重，已有任务时显示当前进度，不会重复添加。
- 手机必须能连上 NAS（同一局域网，或通过 ZeroTier 连到 `10.144.0.1`）。
- 需要浏览器支持 `GM_xmlhttpRequest`（Via 和 Tampermonkey 都支持）。

## 亮度和音量

亮度和音量只调当前视频，不需要任何外部服务。亮度最高 100%，即当前系统亮度，往下最低调到 15%，下次打开视频页会沿用；音量最高 100%，即当前系统音量。iOS 不允许网页修改视频音量，所以 iOS 上右滑音量无效，亮度可用。
