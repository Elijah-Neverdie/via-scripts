# MissAV Via 辅助

给 [Via](https://via-app.cn/) 用的 MissAV 用户脚本，当前版本 **1.5.1**。

安卓和 iOS 使用同一个安装包。脚本先走安卓可用的「插入页面脚本」；如果这段脚本没有执行（iOS 的 Via 会这样），再在当前页面里直接接手势。标记写在页面上，后一条发现前一条已经运行就会退出，因此两条路径不会同时生效。

左滑系统亮度和右滑系统音量只在安卓本机服务可用时生效，这项差异不单独再发一个插件。

匹配 `missav.ai`、`missav.com`、`missav.ws`、`missav.live`、`thisav.com` 及其子域名。

安装或更新地址：

https://github.com/Elijah-Neverdie/via-scripts/releases/latest/download/missav.user.js

在 Via 里打开「设置 → 脚本 → 更新」。更新后刷新正在看的视频页，新手势才会生效。

## 已完成的功能

### 播放

- 单击画面只开关原生控制条（进度、播放、音量、设置、全屏），不会因此播放或暂停。
- 双击左侧三分之一后退 15 秒，画面左侧中央显示 `-15s`。
- 双击中间三分之一播放或暂停。
- 双击右侧三分之一前进 15 秒，画面右侧中央显示 `+15s`。
- 连续快进、快退会累加。竖屏、横屏和全屏都按画面三分区判断。
- 提示只有带阴影的文字，没有底框，也不加粗；字号参考视频标题。全屏时按画面面积缩放。
- 控制条展开后，额外提供 10 秒、1 分钟、10 分钟的快进和快退，全屏同样可用。
- 进入播放页保持暂停，使用页面原有的中央播放按钮。

### 界面

- 首页仍是原来的视频网格，不出现播放和快进层。
- 去掉播放器下方带「循环播放」的那一行，以及同一条黑底里的内容，中间不留空白。
- 播放器齿轮改为下载图标。点击后复制当前正在播放的地址，并提示「已复制下载链接」，不会打开设置菜单。
- 分享按钮旁边增加「复制」，一次复制番号、标题和当前页面链接。

### 手势

- 在画面左半边上下滑动，调节系统屏幕亮度。
- 在画面右半边上下滑动，调节系统媒体音量，与音量键同一路。
- 长按画面 0.5 秒后不松手，左右拖动可以调整进度，画面中央显示时间。

### 广告

- 屏蔽延迟出现在右下角的悬浮广告。
- 推荐视频卡片保持显示，不会被误藏，也不会在右下角来回闪烁。
